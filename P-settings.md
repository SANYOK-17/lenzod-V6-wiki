# P Settings

P0 - Unknown (Value: 43) (read only)
P1 - Speed unit
- km/h
- mph

P2 - Cruise control
- ON
- OFF

P3 - Kick start
- ON
- OFF

P4 - Wheel diameter
Only changes the value displayed in the mobile app.

P5 - Battery voltage
Only changes the value displayed in the mobile app.

P6 - Factory reset

P7 - Bluetooth
- ON
- OFF

P8 - Throttle test

P9 - Brake test

## Notes

- P4 and P5 do not appear to affect the controller.
- They only change the information shown in the mobile app.
- Tested on XM-FY24-PCB-V6.
