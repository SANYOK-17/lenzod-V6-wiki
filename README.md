# Lenzod

Lenzod is a little-known manufacturer of electric scooter electronics, including controllers, displays, throttles, and complete controller kits.

Their products are commonly found in generic or unbranded electric scooters, but very little technical documentation is available online.

Known controller variants include:
- Lenzod (16A)
- Lenzod Max (18A)
- Silver case version
- Black case version

This repository aims to document the Lenzod V6 controller and display based on reverse engineering and real-world testing.
